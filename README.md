Shopify Spy Dropshipping

A Chrome extension for Shopify store analysis, traffic insights, AI-powered competitor research, and ecommerce intelligence.

## Features

- Shopify detection
- Theme detection
- App stack analysis
- Website traffic analytics
- AI-powered store analysis
- Winning product insights
- Recommended competitor shops

## Installation

1. Download or clone the repository
2. Open Chrome
3. Go to chrome://extensions
4. Enable Developer Mode
5. Click "Load unpacked"
6. Select the extension folder
